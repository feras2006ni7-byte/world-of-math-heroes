# عالم الأبطال الرياضي — World of Math Heroes

مشروع تعليمي تفاعلي للمرحلة الأساسية، يهدف إلى دعم تعلم مفاهيم الرياضيات من خلال المغامرات والتحديات والشخصيات التعليمية.

## حالة المشروع
هذه المستودع مخصص لنسخة الويب التجريبية. الواجهة يمكن فتحها من متصفح Android أو الكمبيوتر، بينما يعمل الخادم وقاعدة البيانات على خدمات استضافة خارجية.

## النشر المخطط
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js + Express
- Database: PostgreSQL (Neon)
- Hosting: Render

## قرارات التسجيل المعتمدة
- التسجيل الذاتي للطلاب.
- البريد المستخدم للتسجيل يجب أن ينتهي بـ `@ajyal.jo`، ويُستخدم كبيان تعريفي فقط.
- لا يوجد تحقق من ملكية البريد أو إرسال رموز تفعيل، ولا يوجد اتصال رسمي بمنصة أجيال.
- التسجيل العام ينشئ حساب طالب فقط؛ لا يمكن للطالب اختيار دور معلم أو مدير.
- كلمات المرور تُخزّن باستخدام Argon2id، والجلسات محفوظة في PostgreSQL.

## تنبيه
هذا نموذج أولي تعليمي، وليس خدمة إنتاجية جاهزة للتعامل مع بيانات مدرسية حساسة. يجب إجراء اختبارات أمنية وتشغيلية وتهيئة النسخ الاحتياطي قبل الاستخدام الواسع.
